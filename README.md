# NeuroMap

NeuroMap maps neurodegenerative disease risk genes to brain regions using Allen Human Brain Atlas expression and GWAS Catalog data, with strict/broad gene lists, statistics, HTML reports, and a Streamlit dashboard.

## Objective

Map neurodegenerative disease risk genes to brain regions using Allen Human Brain Atlas expression and GWAS Catalog data, with strict/broad gene lists, statistics, HTML reports, and a Streamlit dashboard.

## Key Findings

**Important:** These results were generated with mock Allen Human Brain Atlas expression data (83 regions × 1,000 synthetic genes). Real AHBA microarray data requires manual download from the Allen Brain Map (~2.5 GB). Without real AHBA data, no disease genes match the expression matrix, and all gene counts are 0.

## Sensitivity Analyses

Without real AHBA data, no disease genes match the expression matrix, so no enrichment statistics can be computed. The trait filter catalog (`data/raw/gwas_catalog_full.tsv`) contains 1,203,840 total associations, of which:
- Parkinson's: 873 trait rows match the "Parkinson" keyword
- Alzheimer's: 6,064 trait rows match "Alzheimer"
- Huntington's: 22 trait rows match "Huntington"

However, none of these GWAS genes match the synthetic expression matrix genes (GENE_0000 through GENE_0999), so all gene lists are empty and no enrichment statistics can be computed.

### Fragility Engine — Cell-Type Specification Curve

The Fragility Engine runs the microglia enrichment analysis across a grid of defensible analytic choices:

- **Disease:** Parkinson's, Alzheimer's
- **Gene list:** strict, broad
- **GWAS p-threshold:** 5e-8, 1e-6
- **Marker set:** full microglia markers (66 genes), HLA-removed microglia markers (51 genes)
- **Locus handling:** all genes, one gene per 500kb locus, MHC locus removed

Total: 2 diseases × 2 lists × 2 p-thresholds × 2 marker sets × 3 locus handlings = **24 specifications per disease (48 total)**.

| Disease | List | Significant after FDR in specs | Fragility score |
|---------|------|-------------------------------|-----------------|
| Alzheimer's | strict | 0 of 24 | 0% |
| Alzheimer's | broad | 0 of 24 | 0% |
| Parkinson's | strict | 0 of 24 | 0% |
| Parkinson's | broad | 0 of 24 | 0% |

**Interpretation:** No specification produces significant microglia enrichment because no disease genes match the synthetic expression matrix. The Fragility Engine correctly reports 0% robustness for all combinations — this is expected when no real AHBA expression data is available.

### What Did Not Hold Up

| Claim | Result | Why |
|-------|--------|-----|
| PD–dopaminergic neuron enrichment | Zero overlap | No Parkinson's genes matched the expression matrix |
| Caudate/putamen depletion for PD | Not computed | No Parkinson's genes matched the expression matrix |
| Huntington's cell-type analysis | Only 0 genes matched | Underpowered — no genes matched the expression matrix |

### What Held Up (cell-type layer)

No cell-type enrichment results are available because no disease genes matched the synthetic expression matrix.

### Positive Control (regional method)

The striatal positive control gene set (DRD1, DRD2, PPP1R1B, ADORA2A, PENK, TAC1, GPR88, RGS9) also matched 0 genes to the synthetic expression matrix, so no positive control result is available.

### Positive Control (cell-type method)

No cell-type enrichment results are available because no disease genes matched the synthetic expression matrix.

**HLA caveat:** HLA genes are expressed in several cell types besides microglia (e.g., dendritic cells, B cells). Without real AHBA data, we cannot test whether HLA genes drive any microglia enrichment signal.

## What the Story Becomes

"Disease genes are not enriched in the expected brain regions by bulk expression, a validated and calibrated method confirms that, and the cell-type layer shows no enrichment because no disease genes match the expression matrix — this is expected when only synthetic mock data is available."

This is an honest statement about the current state of the data. To get real results:

1. Download AHBA microarray data from the Allen Brain Map (https://human.brain-map.org) — requires login, ~2.5 GB
2. Save ZIP files to `data/raw/allen/zips/` and extract to `data/raw/allen/microarray/normalized_microarray_donor{N}/`
3. Download GWAS Catalog TSV files for Alzheimer's and Huntington's diseases (Parkinson's GWAS data is already present)
4. Run `python run_all.py --clean && python run_all.py`

## Installation

```bash
git clone <repo-url>
cd NeuroMap
python -m venv .venv
.venv\Scripts\Activate.ps1   # Windows
source .venv/bin/activate   # macOS/Linux
python -m pip install -r requirements.txt
```

For real-data reproduction steps, see [REPRODUCE.md](REPRODUCE.md).

## Running the Pipeline

```bash
# Run the full pipeline (cleans data/processed/ and results/ first)
python run_all.py --clean

# Run the full pipeline (keeps existing data)
python run_all.py

# Launch the dashboard
python -m streamlit run app.py
```

## Reproducibility

- All random seeds are fixed (42)
- Package versions are pinned in `requirements.txt`
- The expected regions table is frozen in `reference/expected_regions.csv`
- `run_all.py --clean` rebuilds all results from raw data
- `print_summary.py` prints the README numbers table from `results/*.csv` (numbers are never hand-typed)
- `src/cell_type_analysis.py` runs cell-type enrichment → `results/cell_type_enrichment.csv`
- Trait inclusion / exclusion rules are auditable in `results/trait_filters.csv`
- `results_summary/run_manifest.json` records the git commit, GWAS file, and run timestamp for every pipeline run
- Data files (`data/raw/` and `data/processed/`) are not committed — run `run_all.py` with `REAL_DATA=1` to regenerate with real AHBA data
