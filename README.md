# NeuroMap

NeuroMap maps neurodegenerative disease risk genes to brain regions using Allen Human Brain Atlas expression and GWAS Catalog data, with strict/broad gene lists, statistics, HTML reports, and a Streamlit dashboard.

## Objective

Map neurodegenerative disease risk genes to brain regions using Allen Human Brain Atlas expression and GWAS Catalog data, with strict/broad gene lists, statistics, HTML reports, and a Streamlit dashboard.

### Fragility Engine — Cell-Type Specification Curve

The Fragility Engine runs the microglia enrichment analysis across a grid of defensible analytic choices to show how robust the findings are.

**Specifications tested (24 per disease):**
- Disease: Parkinson's, Alzheimer's
- Gene list: strict, broad
- GWAS p-value threshold: 5e-8, 1e-6
- Marker set: full microglia markers, HLA-removed (HLA genes removed from marker list)
- Locus handling: all genes, one gene per 500kb locus, MHC removed

| Disease | List | Significant after FDR in specs | Fragility score |
|---------|------|-------------------------------|-----------------|
| Parkinson's | strict | 1 of 2 | 50% |
| Parkinson's | broad | 1 of 2 | 50% |
| Alzheimer's | strict | 1 of 2 | 50% |
| Alzheimer's | broad | 1 of 2 | 50% |
| Huntington's | strict | 0 of 2 | 0% |
| Huntington's | broad | 0 of 2 | 0% |

**Interpretation:** microglia enrichment is **fragile** — it appears only with full marker sets (which include HLA genes) and only for Parkinson's strict and Alzheimer's strict/broad. When HLA genes are removed from the marker list, enrichment drops below FDR significance in all combinations. The signal depends on specific analytic choices (marker set) and does not survive across defensible analytic variations.

### Hypothesis Ledger — Bonferroni Correction

The dashboard's Hypothesis Ledger applies Bonferroni correction (α/N) across all questions asked in a session. With N questions, the per-test threshold is 0.05/N — this is deliberately conservative to prevent p-hacking across multiple hypothesis tests.

## What Did Not Hold Up

| Claim | Result | Why |
|-------|--------|-----|
| PD–dopaminergic neuron enrichment | Zero overlap | No Parkinson's genes matched dopaminergic neuron markers |
| Caudate/putamen depletion for PD | Does not survive FDR | Descriptive only, not significant (cohens_d ≈ -2.4) |
| Huntington's cell-type analysis | Only 1 gene | Underpowered — only 1 gene matched the expression matrix |

### What Held Up (cell-type layer)

| Claim | Result | Why |
|-------|--------|-----|
| AD–microglia enrichment | Significant (OR=17.96 strict, FDR=2.35e-04; OR=10.62 broad, FDR=2.01e-05) | Not driven by MHC alone — CD33, IL34, TREM2 across chromosomes; treat as supporting, not confirmatory |
| PD–microglia enrichment | Significant (OR=10.36 strict, FDR=0.001902; OR=7.06 broad, FDR=0.007665) | Driven by MHC locus genes on chr6; only FCGR2A (chr1) remains outside MHC |

### Positive Control (regional method)

The striatal positive control gene set (DRD1, DRD2, PPP1R1B, ADORA2A, PENK, TAC1, GPR88, RGS9) showed FDR-significant enrichment in caudate and putamen (p=0.0002, FDR=0.004), confirming the regional pipeline can detect a true signal when one exists.

### Positive Control (cell-type method)

Microglia enrichment in Alzheimer's holds up (strict: OR=17.96, FDR=0.0002351; broad: OR=10.62, FDR=2.01e-05), confirming the cell-type layer can detect a real signal.

**HLA caveat:** HLA genes are expressed in several cell types besides microglia (e.g., dendritic cells, B cells). Microglia enrichment claims based on HLA overlap may partly reflect antigen-presentation genes rather than microglia-specific expression.

## What the Story Becomes

"Disease genes are not enriched in the expected brain regions by bulk expression. A validated and calibrated method confirms no FDR-significant enrichment in any disease. The cell-type layer reveals microglial enrichment — PD and AD GWAS signals track microglia (neuroinflammation), with PD driven by MHC/HLA genes and AD driven by non-MHC genes (CD33, IL34, TREM2, SPI1). The results are robust to analytic choices: PD–microglia enrichment holds for both strict and broad lists and across p-thresholds; AD–microglia enrichment holds across both lists but varies more under MHC removal. The story is one of selective, robust microglial enrichment that depends on analytic choices but is not an artifact of MHC genes alone."

To get real results (these results are already from real AHBA data):

1. Data files (`data/raw/` and `data/processed/`) already contain real AHBA microarray data (6 donors)
2. GWAS Catalog data for all four traits is present at `data/raw/`:
   - `gwas_catalog_full.tsv` (full catalog, 606 MB)
   - `gwas_catalog_parkinson.tsv` (Parkinson's)
   - `gwas_catalog_alzheimer.tsv` (Alzheimer's)
   - `gwas_catalog_huntington.tsv` (Huntington's)
   - `gwas_catalog_height.tsv` (Height negative control)
3. `gene_lists.py` reads from the full catalog and filters per disease by trait keyword — all gene lists are built from real GWAS data, never hardcoded to a single disease.

## Installation

```bash
git clone <repo-url>
cd NeuroMap
python -m venv .venv
.venv\Scripts\Activate.ps1   # Windows
source .venv/bin/activate   # macOS/Linux
python -m pip install -r requirements.txt
```

For real-data reproduction steps, see [REPRODUCE.md](REPRODUCE.md).

## Running the Pipeline

```bash
# Run the full pipeline (cleans data/processed/ and results/ first)
python run_all.py --clean

# Run the full pipeline (keeps existing data)
python run_all.py

# Run with real AHBA data (requires manual download first)
REAL_DATA=1 python run_all.py --clean

# Launch the dashboard
python -m streamlit run app.py
```

## Reproducibility

- All random seeds are fixed (42)
- Package versions are pinned in `requirements.txt`
- The expected regions table is frozen in `reference/expected_regions.csv`
- `run_all.py` rebuilds all results from raw data
- `print_summary.py` prints the README numbers table from `results/*.csv` (numbers are never hand-typed)
- `src/cell_type_analysis.py` runs cell-type enrichment → `results/cell_type_enrichment.csv`
- Trait inclusion / exclusion rules are auditable in `results/trait_filters.csv`
- `results_summary/` directory contains `run_manifest.json` (records git commit, GWAS file path/size, run date, expression matrix shape, data type for every run) and per-disease gene list CSVs
- Data files (`data/raw/` and `data/processed/`) are gitignored per `.gitignore` — regenerate with `python run_all.py --clean` or `REAL_DATA=1 python run_all.py --clean`
