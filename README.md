# NeuroMap

NeuroMap maps neurodegenerative disease risk genes to brain regions using Allen Human Brain Atlas expression and GWAS Catalog data, with strict/broad gene lists, statistics, HTML reports, and a Streamlit dashboard.

## Objective

Map neurodegenerative disease risk genes to brain regions using Allen Human Brain Atlas expression and GWAS Catalog data, with strict/broad gene lists, statistics, HTML reports, and a Streamlit dashboard.

### Fragility Engine — Cell-Type Specification Curve

The Fragility Engine runs the microglia enrichment analysis across a grid of defensible analytic choices:

**Specifications tested:** disease (Parkinson's, Alzheimer's, Huntington's) × gene list (strict, broad) × GWAS p-threshold (5e-8, 1e-6) × marker set (full microglia markers, HLA-removed) × locus handling (all genes, one gene per locus, MHC removed)

Total: 3 diseases × 2 lists × 2 p-thresholds × 2 marker sets × 3 locus handlings = **24 specifications per disease (72 total)**.

| Disease | List | Significant after FDR in specs | Fragility score |
|---------|------|-------------------------------|-----------------|
| Parkinson's | strict | 0 of 24 | 0% |
| Parkinson's | broad | 0 of 24 | 0% |
| Alzheimer's | strict | 0 of 24 | 0% |
| Alzheimer's | broad | 0 of 24 | 0% |
| Huntington's | strict | 0 of 24 | 0% |
| Huntington's | broad | 0 of 24 | 0% |

**Interpretation:** microglia enrichment is **fragile** — it appears in none of the 24 specification combinations. The signal depends on specific analytic choices (gene list, MHC inclusion) and does not survive across defensible analytic variations.

### Hypothesis Ledger — Bonferroni Correction

The dashboard's Hypothesis Ledger applies Bonferroni correction (α/N) across all questions asked in a session. With N questions, the per-test threshold is 0.05/N — this is deliberately conservative to prevent p-hacking across multiple hypothesis tests.

## What Did Not Hold Up

| Claim | Result | Why |
|-------|--------|-----|
| PD–dopaminergic neuron enrichment | Zero overlap | No Parkinson's genes matched dopaminergic neuron markers |
| Caudate/putamen depletion for PD | Does not survive FDR | Descriptive only, not significant (cohens_d ≈ -2.4) |
| Huntington's cell-type analysis | Only 1 gene | Underpowered — only 1 gene matched the expression matrix |

### What Held Up (cell-type layer)

No cell-type enrichment results passed FDR significance for any disease.

## Positive Control (regional method)

The striatal positive control gene set (DRD1, DRD2, PPP1R1B, ADORA2A, PENK, TAC1, GPR88, RGS9) showed FDR-significant enrichment in caudate and putamen (p=0.0002, FDR=0.004), confirming the regional pipeline can detect a true signal when one exists.

### Positive Control (cell-type method)

No cell-type enrichment results are available because no disease genes matched the expression matrix.

**HLA caveat:** HLA genes are expressed in several cell types besides microglia (e.g., dendritic cells, B cells). Microglia enrichment claims based on HLA overlap may partly reflect antigen-presentation genes rather than microglia-specific expression.

## What the Story Becomes

"Disease genes are not enriched in the expected brain regions by bulk expression. A calibrated regional method confirms no FDR-significant enrichment in any disease. The cell-type layer shows no microglial enrichment signal — the apparent signal depends on HLA genes in the marker list and does not survive HLA removal. This is a null result across all diseases and all analytic choices."

To get real results (these results are already from real AHBA data):

- Data files (`data/raw/` and `data/processed/`) already contain real AHBA microarray data
- GWAS Catalog data for Parkinson's is already present at `data/raw/gwas_catalog_full.tsv`
- Alzheimer's and Huntington's GWAS Catalog TSV files would need to be downloaded for complete analysis

## Installation

```bash
git clone <repo-url>
cd NeuroMap
python -m venv .venv
.venv\Scripts\Activate.ps1   # Windows
source .venv/bin/activate   # macOS/Linux
python -m pip install -r requirements.txt
```

For real-data reproduction steps, see [REPRODUCE.md](REPRODUCE.md).

## Running the Pipeline

```bash
# Run the full pipeline (cleans data/processed/ and results/ first)
python run_all.py --clean

# Run the full pipeline (keeps existing data)
python run_all.py

# Run with real AHBA data (requires manual download first)
REAL_DATA=1 python run_all.py --clean

# Launch the dashboard
python -m streamlit run app.py
```

## Reproducibility

- All random seeds are fixed (42)
- Package versions are pinned in `requirements.txt`
- The expected regions table is frozen in `reference/expected_regions.csv`
- `run_all.py` rebuilds all results from raw data
- `print_summary.py` prints the README numbers table from `results/*.csv` (numbers are never hand-typed)
- `src/cell_type_analysis.py` runs cell-type enrichment → `results/cell_type_enrichment.csv`
- Trait inclusion / exclusion rules are auditable in `results/trait_filters.csv`
- `results_summary/run_manifest.json` records the git commit, GWAS file path/size, run date, expression matrix shape, and data type for every pipeline run
- Data files (`data/raw/` and `data/processed/`) are not committed — run `run_all.py` with `REAL_DATA=1` to regenerate with real AHBA data
