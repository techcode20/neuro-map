# NeuroMap

NeuroMap maps neurodegenerative disease risk genes to brain regions using Allen Human Brain Atlas expression and GWAS Catalog data, with strict/broad gene lists, statistics, HTML reports, and a Streamlit dashboard.

## Objective

Map neurodegenerative disease risk genes to brain regions using Allen Human Brain Atlas expression and GWAS Catalog data, with strict/broad gene lists, statistics, HTML reports, and a Streamlit dashboard.

## Sensitivity Analyses

Microglia overlap genes (computed as `results_summary/gene_list_*.csv` ∩ `reference/cell_markers.csv`):

| Disease | List | Overlap genes | In MHC locus (chr6:25-35Mb) |
|---------|------|---------------|-----------------------------|
| Parkinson's | strict | FCGR2A, HLA-DQB1, HLA-DRA, HLA-DRB1, HLA-DRB5 | 4 of 5 |
| Parkinson's | broad | FCGR2A, HLA-DQB1, HLA-DRA, HLA-DRB1, HLA-DRB5 | 4 of 5 |
| Alzheimer's | strict | CD33, HLA-DRB1, HLA-DRB5, IL34, TREM2 | 2 of 5 |
| Alzheimer's | broad | CD33, HLA-DQB1, HLA-DRA, HLA-DRB1, HLA-DRB5, IL34, MRC1, SPI1, TREM2 | 4 of 9 |

Locus assignments (500kb windows around lead-SNP positions; see `results_summary/overlap_loci.csv`):

| Disease | List | Loci | MHC locus genes |
|---------|------|------|-----------------|
| Parkinson's | strict | chr1_locus1 (FCGR2A), chr6_locus2 (HLA-DRA/HLA-DRB1/HLA-DRB5/HLA-DQB1) | HLA-DRA, HLA-DRB1, HLA-DRB5, HLA-DQB1 |
| Parkinson's | broad | Same as strict | Same as strict |
| Alzheimer's | strict | chr6_locus1 (HLA-DRB1/HLA-DRB5), chr6_locus2 (TREM2), chr16_locus3 (IL34), chr19_locus4 (CD33) | HLA-DRB1, HLA-DRB5 |
| Alzheimer's | broad | chr6_locus1 (HLA-DRB1/HLA-DRB5), chr6_locus2 (TREM2/HLA-DQA1/HLA-DQB1), chr16_locus3 (IL34), chr19_locus4 (CD33), plus others | HLA-DRA, HLA-DQB1, HLA-DRB1, HLA-DRB5 |

- **PD–microglia:** 4 of 5 overlap genes are HLA genes on chr6 (MHC locus); only FCGR2A (chr1) lies outside MHC. Enrichment is driven by the MHC locus.
- **AD–microglia:** Not driven by MHC alone — CD33 (chr19), IL34 (chrX), TREM2 (chr6p21, separate from MHC) and SPI1 (chr11) are non-MHC genes. Consistent with known microglial involvement in AD, but the marker list and AD gene list are not fully independent, so treat as supporting rather than confirmatory.

**Dopaminergic neuron CI:** OR=0 with zero overlap between PD strict genes and dopaminergic neuron markers. CI not estimable ([0, inf]). Low power — cannot conclude absence.

### What Did Not Hold Up

| Claim | Result | Why |
|-------|--------|-----|
| PD–dopaminergic neuron enrichment | Zero overlap, CI not estimable | Low power (0 overlap with 23 dopaminergic markers) — cannot conclude absence |
| Caudate/putamen depletion for PD | Does not survive two-sided FDR | Descriptive only, not a significant finding (cohens_d ≈ -2.5, FDR ≈ 0.99) |
| Huntington's cell-type analysis | Only 1 gene | Underpowered — not analyzable |

### What Held Up (cell-type layer)

| Claim | Result | Why |
|-------|--------|-----|
| AD–microglia enrichment | Significant (OR=7.16 strict, FDR=2.35e-04; OR=4.13 broad, FDR=4.13e-02) | Not driven by MHC alone — CD33, IL34, TREM2 across chromosomes; treat as supporting, not confirmatory |
| PD–microglia enrichment | Significant (OR=10.36 strict, FDR=1.9e-03; OR=7.06 broad, FDR=7.7e-03) | Driven by MHC locus genes on chr6; only FCGR2A (chr1) remains outside MHC |

### Positive Control (regional method)

The real positive control for the regional method is the striatal gene set (DRD1, DRD2, PPP1R1B, ADORA2A, PENK, TAC1, GPR88, RGS9). Caudate and putamen are FDR-significant (p=0.0002, FDR=0.004), confirming the regional pipeline can detect a true signal when one exists.

### Positive Control (cell-type method)

Microglia enrichment in Alzheimer's holds up (strict: OR=7.16, FDR=2.35e-04; broad: OR=4.13, FDR=4.13e-02), confirming the cell-type layer can detect a real signal.

**HLA caveat:** HLA genes are expressed in several cell types besides microglia (e.g., dendritic cells, B cells), so microglia-enrichment claims based on HLA overlap may partly reflect antigen-presentation genes in general.

## What the Story Becomes

"Disease genes are not enriched in the expected brain regions by bulk expression, a validated and calibrated method confirms that, and the cell-type layer shows which cell types the genes actually belong to — but with important caveats about overlap-gene independence and low power."

This is a stronger, more honest narrative than a forced positive result:

- Bulk regional expression shows **no significant enrichment** for Parkinson's (0 regions pass FDR)
- Caudate/putamen show **depletion** (not enrichment), consistent across all 6 donors (cohens_d ≈ -2.4), but this **does not survive two-sided FDR correction** — treat as descriptive only
- The **cell-type layer** reveals that PD and AD GWAS signals track microglia (neuroinflammation), not cell-type-specific vulnerability

## Installation

```bash
git clone <repo-url>
cd NeuroMap
python -m venv .venv
.venv\Scripts\Activate.ps1   # Windows
source .venv/bin/activate   # macOS/Linux
python -m pip install -r requirements.txt
```

For real-data reproduction steps, see [REPRODUCE.md](REPRODUCE.md).

## Running the Pipeline

```bash
# Run the full pipeline
python run_all.py

# Launch the dashboard
python -m streamlit run app.py
```

## Reproducibility

- All random seeds are fixed (42)
- Package versions are pinned in `requirements.txt`
- The expected regions table is frozen in `reference/expected_regions.csv`
- `run_all.py` rebuilds all results from raw data
- `print_summary.py` prints the README numbers table from `results/*.csv` (numbers are never hand-typed)
- `cell_type_analysis.py` runs cell-type enrichment → `results/cell_type_enrichment.csv`
- Trait inclusion / exclusion rules are auditable in `results/trait_filters.csv`
- Data files (`data/raw/` and `data/processed/`) are not committed — run `run_all.py` with `REAL_DATA=1` to regenerate
